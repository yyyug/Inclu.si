# Digest 優化：縮短 lookback + 候選人上限

## 修改 1：Workflow lookback 36hr → 24hr

**檔案**: `.github/workflows/daily-digest.yml`，line 44

```yaml
DIGEST_LOOKBACK_HOURS: 24
```

## 修改 2：Digest 腳本加候選人上限

**檔案**: `scripts/generate-daily-digest.mjs`，`main()` 函數

在 EN/ZH-TW 過濾後加 `.slice(0, MAX_DIGEST_CANDIDATES)`：

```javascript
const MAX_DIGEST_CANDIDATES = 100;
const enRows = rows.filter((item) => item.lang === 'en').slice(0, MAX_DIGEST_CANDIDATES);
const zhRows = rows.filter((item) => item.lang === 'zh-TW').slice(0, MAX_DIGEST_CANDIDATES);
```
